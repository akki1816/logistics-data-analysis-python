# Kolkata Logistics Data Analysis

## Project Overview
This project analyzes sample logistics shipment data to understand delivery delays across different hubs in Kolkata.

## Objectives
- Analyze total shipments.
- Identify delayed shipments.
- Calculate delay percentages.
- Compare logistics hub performance.
- Identify hubs with the highest delays.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Methodology
1. Data collection using sample logistics records.
2. Data preprocessing.
3. Delay percentage calculation.
4. Hub-wise performance analysis.
5. Data visualization.

## Results
The analysis identifies the hub with the highest number of delayed shipments using demonstration data.

## Disclaimer
This project uses simulated sample data for educational purposes. It does not represent actual company records.
