
# Project Results Report

## 1. Introduction
This project analyzes sample logistics shipment data for Kolkata.

## 2. Analysis Performed
- Total shipment analysis
- Delayed shipment analysis
- Hub-wise comparison
- Delay percentage calculation
- Identification of the highest-delay hub

## 3. Tools Used
- Python
- Pandas
- Matplotlib

## 4. Key Findings
The analysis compares shipment delays across Kolkata, Howrah and Durgapur hubs.

The highest-delay hub is identified using the sample dataset.

## 5. Conclusion
Data analysis helps logistics companies monitor delivery performance and identify areas requiring improvement.

## 6. Limitation
The dataset is simulated for educational purposes and does not contain actual company shipment records.
